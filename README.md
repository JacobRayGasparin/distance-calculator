# 2D Distance Calculator

## Description
This program is a simple command-line tool written in Python that calculates the straight-line (Euclidean) distance between two coordinate points, \((x_1, y_1)\) and \((x_2, y_2)\), in a two-dimensional grid. It utilizes Python's built-in `math` library for precise square root and power operations.

## How to Run the Program
1. Ensure you have Python installed on your computer.
2. Open your terminal or command prompt.
3. Navigate to the folder containing the script.
4. Run the program using the following command:
   ```bash
   python distance_calculator.py
   ```

## Input Needed
The program requires 4 numeric values (integers or floating-point numbers) provided by the user via the console:
* `x coordinate for Point 1`
* `y coordinate for Point 1`
* `x coordinate for Point 2`
* `y coordinate for Point 2`

## Sample Output
```text
--- 2D Distance Calculator ---
Enter x coordinate for Point 1: 1
Enter y coordinate for Point 1: 2
Enter x coordinate for Point 2: 4
Enter y coordinate for Point 2: 6

The distance between the two points is: 5.00
```
